# 基于Arduino的五轴机械臂控制系统 (Arduino Robotic Arm V1.0)

## 项目简介
本项目从零搭建了一台五自由度桌面级机械臂，实现了底层舵机驱动、串口文本协议控制、平滑移动算法以及安全防堵转保护。

## 硬件清单
*   主控板：Arduino Uno R3
*   舵机驱动板：PCA9685 (16路 PWM)
*   执行机构：5 x MG996R 舵机
*   电源：5V 2A DC 电源适配器（舵机独立供电）

## 核心功能
*   **串口文本协议控制**：支持通过上位机发送“关节号,角度”（如“0,90”）指令，实现精准位置控制。
*   **平滑移动算法**：采用“smoothMove”函数，每步1度延时8ms，解决舵机开环控制中的指令积压与丢步问题。
*   **安全防护逻辑**：内置软限位保护，防止机械臂撞死；夹爪设置了40°~140°的防堵转保护区间。
*   **安全复位功能**：输入“R”指令可自动归中，复位顺序为先收拢大臂小臂，最后旋转底座，防止倾倒与线缆绞缠。

## 工程排障记录
*   **夹爪堵转问题**：通过“物理隔离测试”定位到机械零点偏移，重新对齐齿轮零点并在代码中调整软限位，彻底解决夹爪卡死烧毁的隐患。
*   **供电干扰**：采用“逻辑电与动力电分离”方案，舵机独立供电，避免电流不足导致抖动。
